# Relics and Utilities

All crafting recipes below are described in text for clarity.

## Void Translocator
- **Function:** Instant spatial blink (`24m` Basic / `36m` Netherite) through solid obstacles with fall-damage reset and Electro self-aura (`5.0s` CD). Can be absorbed into the **Omni Staff** (Electro slot) via Crafting or Anvil.
- **Crafting (Text Guide):** Combine **Ender Pearl + Electro Element + Amethyst Shards / Blaze Rods** in a Crafting Table.

## Magic Mirror
- **Function:** Channels to recall back to your Bed or World Spawn point (`15.0s` CD; Netherite supports cross-dimensional recall).
- **Crafting (Text Guide):** Combine **Glass + Ender Pearl + Gold/Diamond** in a Crafting Table; upgrade to Netherite in a Smithing Table.

## Elemental Codex
- **Function:** Interactive in-game guidebook with clickable reaction links, live server config sync, and 9-language localization.
- **Crafting (Text Guide):** Combine **Book + Elemental Essence** in a Crafting Table.

## Omni Element
- **Function:** Universal essence used to repair any staff, convert any staff into an Omni Staff in an Anvil, or imbue swords.
- **Crafting (Text Guide):** Combine all **7 Elemental Essences** (`pyro_element`, `hydro_element`, `cryo_element`, `electro_element`, `anemo_element`, `geo_element`, `dendro_element`) in a Crafting Table.
